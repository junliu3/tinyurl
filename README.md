# tiny URL - 短地址服务

## 需求
- 把原始 URL 转换成一个短地址（5个字符，一个5位的62进制数）
- 输入短地址获得原始 URL
- 查看统计信息：所有的原始地址及短地址
- 统计每一个短地址的解析次数
- 设置短地址的有效次数
- ...

URL: 统一资源定位符，长度 2k ~ 4k，
