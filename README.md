# TinyURL - 短地址服务

基于**单向链表（尾插法）**实现的轻量级短地址服务。

## 功能

| 功能 | 说明 |
|------|------|
| 生成短地址 | 输入原始 URL → 输出 5 位 62 进制短地址码 |
| 解析短地址 | 输入短地址码 → 还原原始 URL（自动计数） |
| 统计信息 | 展示所有映射关系、解析次数、有效次数 |
| 设置有效次数 | 限制短地址的最大解析次数 |
| 删除短地址 | 删除指定映射记录 |

### 数据结构

```
  url_list_t
  ┌──────────────┐     url_node_t        url_node_t
  │ head ──────────────────┬───────────────┬────→ NULL
  │ tail ──────────────────┘               │
  │ size = 2     │     │ original_url    │ original_url
  │ counter = 3  │     │ short_code[6]   │ short_code[6]
  └──────────────┘     │ access_count    │ access_count
                       │ max_access      │ max_access
                       │ next ───────────┤ next = NULL
                       └─────────────────┘
```

### 核心算法

- **生成短地址**：全局计数器 counter → 十进制转 62 进制 → 5 位短码
- **62 进制字符集**：`[0-9 a-z A-Z]`，容量 62⁵ ≈ 9.16 亿
- **解析查找**：链表顺序遍历 O(n)
